# Character Asset Technical Review

Use this checklist before marking a style implementation `approved`.

- [ ] Canonical ID exists and matches exactly.
- [ ] Asset is in the correct style/category directory.
- [ ] Manifest parses and references the correct style.
- [ ] All declared files exist.
- [ ] Runtime export format is approved.
- [ ] Background is transparent.
- [ ] Canvas size matches the style specification.
- [ ] Artwork is positioned against the style canvas, not tightly cropped.
- [ ] Layer names are valid.
- [ ] Multi-layer assets declare every component.
- [ ] Asset contains no unrelated baked-in avatar pieces.
- [ ] Every declared supported body has been tested.
- [ ] No unintended clipping appears in the neutral pose.
- [ ] Equip-slot conflicts are declared where needed.
- [ ] Provenance is present.
- [ ] Runtime filename contains no artist name or manual version suffix.
