# Runtime Exports

Production-ready runtime files for this style would be placed here or generated here by the asset pipeline.

For this example:

- expected format: PNG;
- canvas: 1024 × 1024;
- transparent background;
- preserve full-canvas positioning;
- no manual tight cropping;
- canonical ID used in filename;
- multi-layer items use explicit suffixes such as `.back.png` and `.front.png`.

No runtime art is included in this documentation-only style.
