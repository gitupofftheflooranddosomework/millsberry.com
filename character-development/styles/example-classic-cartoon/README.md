# Example Style Pack: Classic Cartoon

This is a **worked reference example**, not an approved Millsberry Reborn art direction.

Its purpose is to show artists and developers what a properly set-up style pack looks like after the blank template has been filled in. Copy the structure, replace the example values, and use the real style ID assigned to your work.

**Do not ship assets from this folder.** The style is marked as documentation-only and is not eligible to become active.

## What this example demonstrates

- a named style with a written visual direction;
- a fixed working canvas;
- concrete anchor coordinates;
- two compatible body profiles;
- shared layer and equip-slot assumptions;
- filled style-item manifests;
- source/export expectations;
- an example assembled avatar;
- a QA status file;
- a clear distinction between "style information" and "canonical item information".

## Example outfit

The worked avatar uses:

- `body.base_a`
- `hair.short_messy_01`
- `shirt.red_hoodie`
- `pants.blue_jeans`
- `shoes.white_sneakers`
- `hat.blue_cap`
- `glasses.round_black`
- `accessory.backpack_green`

These IDs are illustrative. They are not automatically added to the live game catalog just because this example references them.

## Folder rule

Every real style should be understandable without asking the original artist how it works. The style guide, anchors, body notes, manifests, and approved references should be enough for another artist to continue the work.
