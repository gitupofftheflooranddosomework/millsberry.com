# Example Style Item Implementations

Each item below shows a filled style-side manifest.

The canonical item owns identity and gameplay meaning. These files only describe how `example_classic_cartoon` would render that canonical item.

A real item folder normally contains:

```
style-item.json
<runtime PNG export(s)>
optional source/reference notes
```

This worked example intentionally omits production PNG artwork so nobody mistakes reference material for approved game art.
