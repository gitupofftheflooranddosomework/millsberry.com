# Editable Source Files

Real style packs may keep editable working files here when repository size and licensing make that practical.

Suggested layout:

```
source/
  bodies/
  hair/
  tops/
  bottoms/
  shoes/
  hats/
  glasses/
  accessories/
```

Keep artist-friendly filenames close to the canonical IDs.

Avoid filenames such as:

```
bluecap-final-FINAL-2.psd
```

Prefer:

```
hat.blue_cap.psd
```

If editable source lives outside Git, document the authoritative storage location in the real style's README.
