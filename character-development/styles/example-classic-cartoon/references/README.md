# Approved Style References

A real style should collect a small set of approved references here so contributors can quickly understand what "on style" means.

Useful references include:

- one assembled Body A avatar;
- one assembled Body B avatar;
- one hair example;
- one top;
- one bottom;
- one shoe pair;
- one hat;
- one face accessory;
- one complex/multi-layer item.

References are for visual consistency. They do not replace the written rules in `STYLE.md`.
