# Style Packs

Each child folder represents one visual interpretation of the shared canonical avatar catalog.

Do not create a style folder for one-off items. A style pack is expected to become a coherent, repeatable system.

New styles begin as `incubating`.

Copy `_template/` when starting a new style.

## Worked example

See [example-classic-cartoon/](./example-classic-cartoon/) for a fully filled-out reference style.

It is deliberately **not** production art and is not an approved Millsberry Reborn direction. It exists so contributors can see how the blank template turns into a real working folder: style guide, anchors, body profiles, item manifests, source/export conventions, assembly notes, and QA state.
