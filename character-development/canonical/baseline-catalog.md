# Style Baseline Catalog

This file defines the minimum catalog a new visual style must implement before it can be considered for active player use.

The exact item list will grow as the avatar system is reconstructed and designed. Do not treat the placeholder IDs below as final art direction decisions.

## Required systems

- All approved base body variants
- Default eyes
- Default mouth
- Shared anchor map
- Shared layer map
- At least one complete assembled reference avatar for each required body

## Minimum wardrobe coverage

Before activation, a style should include enough approved canonical items to build multiple complete avatars:

- hair: minimum 6
- tops: minimum 6
- bottoms: minimum 4
- shoes: minimum 4
- headwear: minimum 3
- glasses: minimum 2
- accessories: minimum 2

The actual launch catalog may require more. This baseline is a floor, not a target.

## Promotion rule

A style remains `incubating` until the baseline catalog is complete and both art and technical QA approve it.

Incubating styles do not block releases for active styles.
