# Millsberry Reborn

This directory contains **new work created specifically for Millsberry Reborn**.

Assets in this directory are **not recovered original Millsberry assets** and must not be described or catalogued as original-era material.

Recovered, preserved, or reference material from the original Millsberry project belongs in the repository's existing recovery/reference areas. New Reborn artwork, UI, and other replacement or expanded assets belong here or in another directory that is explicitly marked as Millsberry Reborn work.

## UI artwork

The `ui/` directory contains new Millsberry Reborn interface artwork.

The initial UI set in this directory was contributed through PR #13 by @mannuhx and was intentionally moved out of `base images/` during integration so its provenance is unambiguous.
