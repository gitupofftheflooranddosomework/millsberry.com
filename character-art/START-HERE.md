# START HERE — Millsberry Reborn Character Art

If you are an artist, you do **not** need to understand game code or JSON to contribute character art.

## The simple rule

Every style gets its own folder.

Inside that folder, draw the same kinds of pieces:

1. base body
2. eyes
3. mouth
4. hair
5. shirts
6. pants
7. shoes
8. hats
9. accessories
10. finished examples

All normal avatar PNGs use the same canvas size for that style. In this example the canvas is **1024 × 1024**.

Do not crop around the object. Leave the transparent empty space in place so the game can stack the PNGs.

Open `example-classic-cartoon/10-examples/EXAMPLE-FINISHED-CHARACTER.png` first, then compare it to the individual PNGs in folders 01–09.

The Classic Cartoon folder is only a worked example. It is not the final Millsberry Reborn art direction.
